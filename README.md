## Traffic Light Detection ROS 2

ROS 2 implementation of the traffic-light detection and lane-following system used in the RoverLad autonomous vehicle simulation.

This repository contains the ROS 2 Python package responsible for processing camera data, running the trained traffic-light detection model, detecting road lanes, processing IMU data, and using the resulting perception data to control the simulated vehicle.

The complete project, including the Isaac Sim environment, dataset generation, CNN training process, and system overview, can be found in the main project repository.

Source project: https://github.com/Alexledev/TrafficLightDetectionTutorial/tree/SimulationDeployment
